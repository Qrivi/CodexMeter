# Security

CodexMeter reads the local Codex auth session from `~/.codex/auth.json` to fetch usage information.

## Reporting a Vulnerability

Please report security concerns privately to the repository owner. Include:

- a description of the issue
- steps to reproduce, if known
- any affected versions or commits

Avoid opening public issues for vulnerabilities until they have been triaged.

## Sensitive Data

Do not commit auth files, tokens, build products, or local Xcode user state.
